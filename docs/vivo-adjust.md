# vivo 手机专属适配

## 背景

目标用户都用 vivo 手机（OriginOS / FuntouchOS）。vivo 对后台应用的限制比原生 Android 严格得多，
光有前台服务 + 通知并不够，必须让用户在系统里额外开几个"白名单"开关。

## vivo 特有的后台限制项

| 开关 | 位置 | 作用 |
|---|---|---|
| 自启动 | 设置 → 应用与权限 → 权限管理 → 自启动 | 开机/被清后能自己拉起来 |
| 后台高耗电 | 设置 → 电池 → 后台耗电管理 | 允许后台持续联网 + 保活 |
| 锁屏显示 | 权限管理 → 其他权限 → 锁屏显示 | 锁屏时能弹出提醒 |
| 后台弹出界面 | 权限管理 → 其他权限 → 后台弹出界面 | 后台能弹悬浮窗/全屏提醒 |
| 睡眠模式 | 设置 → 电池 → 更多设置 | 关闭后避免夜间被强制冻结 |

这些项**没有统一的公开 Intent 能一键直达**，只能：
1. 跳 App 详情页让用户逐项开
2. 或直接打开 vivo 手机管家（i管家）

## 本项目做的适配

### 1. 权限门引导（PermissionGate）

启动时强制检查硬权限（悬浮窗、安装未知应用），缺失就弹**不可取消**的引导框，
没有取消键、返回键也锁死 —— 只有授权完才能进主界面。

### 2. vivo 专属引导（一次性）

硬权限都齐了之后，首次进入会再弹一次"需要 vivo 后台权限"的引导，
点「去设置」**直接打开手机管家**，提示用户逐项开启自启动/锁屏显示/后台弹出/后台高耗电。

手机管家的包名兼容了两种：
- `com.iqoo.secure`（iQOO / 较新的 vivo 机型）
- `com.vivo.abe`（部分 OriginOS 机型）

找不到上述包名时，回落 App 详情页兜底。

> 实测本机（vivo V2502A / Android 17）的手机管家包名是 `com.iqoo.secure`，
> 能正常拉起。

### 3. 锁屏全屏提醒

- Manifest 加了 `USE_FULL_SCREEN_INTENT` 权限
- 通知渠道用 `IMPORTANCE_HIGH` + 振动
- 爱心类通知（love=true）加 `setFullScreenIntent(pi, true)`，锁屏时代全屏弹出
- 通知可见性设为 `VISIBILITY_PUBLIC`，锁屏上直接显示内容

## 仍需用户手动确认的

代码能做的都做了，但 vivo 系统里有几个开关**只能靠用户自己点**，
App 无法静默开启（这属于系统安全边界，绕过会被判违规）：

1. 自启动
2. 后台高耗电
3. 锁屏显示
4. 后台弹出界面

所以 App 的引导框只负责"带用户到那个页面"，最后还得用户点一下。
